**Technical Implementation:**
```javascript
// Goal Calculator Formula
function calculateSIP(targetAmount, years, expectedReturn, inflation) {
    const realReturn = (1 + expectedReturn/100) / (1 + inflation/100) - 1;
    const months = years * 12;
    const monthlyRate = realReturn / 12;
    const sip = targetAmount * monthlyRate / (Math.pow(1 + monthlyRate, months) - 1);
    return sip;
}
```

### 2. XIRR Calculator 📈
*Every competitor has this - critical for SIP investors*

**User Need:** "What's my actual return considering all my SIP dates?"

**Features Required:**
- True XIRR for each fund (not just absolute returns)
- Portfolio-level XIRR (weighted)
- Date-wise transaction drill-down
- Compare with benchmark XIRR (Nifty 50, Sensex)
- XIRR breakdown:
  - Since inception
  - 1 Year
  - 3 Year
  - 5 Year
- Visual chart showing XIRR trend over time

**Technical Implementation:**
```javascript
// XIRR requires Newton-Raphson method
function xirr(transactions) {
    // transactions = [{amount: -10000, date: '2023-01-15'}, ...]
    // Positive = redemption, Negative = investment
    let rate = 0.1; // Initial guess
    for (let i = 0; i < 100; i++) {
        let npv = 0, dnpv = 0;
        transactions.forEach(t => {
            const years = (new Date(t.date) - new Date(transactions[0].date)) / 365.25 / 86400000;
            npv += t.amount / Math.pow(1 + rate, years);
            dnpv -= years * t.amount / Math.pow(1 + rate, years + 1);
        });
        rate -= npv / dnpv;
        if (Math.abs(npv) < 0.001) break;
    }
    return rate * 100; // Return as percentage
}
```

**Monetization:** Free
